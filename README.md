# AI Blueprint Help Centre

Customer-facing documentation for [AI Blueprint](https://www.aiblueprint.web.id), built with Mintlify.

## Local preview

```bash
npx mintlify dev
```

The default locale is Bahasa Indonesia. English pages live at the repository root and Indonesian pages under `id/`.

## Content safety

- Use only sanitized screenshots and examples.
- Do not document credentials, provider routing, private Control Room features, or customer data.
- Keep the two language trees semantically aligned.

Changes are intentionally not published until they pass content review and the Mintlify GitHub integration is approved.
