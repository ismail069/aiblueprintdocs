## Dua momen approval

1. **Idea Review / VPC Sign Approve** mengunci Smart Requirement Summary dan konteks produk tervalidasi. Aksi ini otomatis memulai generasi dokumen.
2. **Sign Approve Blueprint** menerima seluruh set versi dokumen saat ini dalam satu tindakan global.

Di antara keduanya, buka setiap kartu dokumen saat ini. Membuka versi saat ini mengubah status review dari **Belum ditinjau** menjadi **Ditinjau**; tindakan ini bukan tanda tangan approval. Stub **Tidak Diperlukan** tetap dihitung sebagai satu dokumen saat ini, jadi buka stub tersebut sekali walaupun tidak ada konten atau perbaikan yang perlu dibuat. Tombol global tersedia setelah generasi selesai, seluruh dokumen saat ini sudah ditinjau, serta tidak ada dokumen **Perlu Perbaikan** atau **Terhambat**.

**Project ZIP** tetap terkunci sampai approval global selesai. Regenerasi, restore, atau versi baru dapat membatalkan approval set sebelumnya. Tinjau kembali set versi saat ini, lalu lakukan **Sign Approve Blueprint** lagi.
