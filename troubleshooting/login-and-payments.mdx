## Email verification and password

1. Confirm you are using the same email address used at registration.
2. Complete the security check before signing in or requesting another verification email.
3. **Resend verification email** becomes available again after two minutes. You can resend at most three times.
4. On the fourth request, the button opens a verification-help form instead of sending another email. The form goes to `halo@aiblueprint.web.id` on the Indonesian domain or `hello@aiblueprintapp.com` on the global domain.
5. Use **Forgot password** for a new reset link. Use only the newest link; reset tokens expire and are single-use.

If the countdown or attempt count looks wrong, refresh once in the same browser. Do not repeatedly switch tabs or addresses to bypass the limit; use the support form after the third resend.

## Google sign-in

Start Google sign-in from the AI Blueprint **Login** or **Register** page. Complete Google consent and allow the browser to return to the AI Blueprint domain you are using: `aiblueprint.web.id` or `aiblueprintapp.com`.

If Google returns a callback error, try once more in the same browser and confirm that popup or cookie restrictions did not block the return. If it fails again, capture the safe error page and time, then contact Support without sharing OAuth tokens, cookies, or passwords.

## Select currency and provider

Use the **IDR / USD** selector on Pricing or **Billing** before checkout:

- IDR uses Midtrans and the Rupiah catalogue;
- USD uses PayPal and the US-dollar catalogue.

The choice persists in that browser for the active domain. `aiblueprint.web.id` initially selects IDR; `aiblueprintapp.com` initially selects USD. See [AI credits and billing](/guides/credits-and-billing) for current prices.

## Midtrans: close, continue, change, or cancel

Closing Snap does not mean success and does not automatically cancel a pending transaction. AI Blueprint can show **Payment is being verified** while it checks the provider's official status.

| What you want | Action on the payment-result page | Result |
| --- | --- | --- |
| Finish the method already selected | **Continue previous method** | Reopens the current valid payment instruction or Snap token. |
| Pick another bank, QRIS, GoPay, or another available method | **Choose another payment method** | Cancels the previous pending instruction when eligible and opens a fresh Snap checkout at all payment methods. No second confirmation is required. |
| Stop this purchase | **Cancel transaction** | Requests cancellation of the eligible open transaction and returns to Billing. No plan or credit is granted. |
| Refresh the official status | **Check again** | Reads the latest verified provider state. |

After you select a VA, QRIS, or e-wallet, Snap may mark the transaction **pending** because customer action is still required. Pending is not success. If the old instruction has expired, start a new checkout; do not transfer to an expired VA or scan an expired QR code.

<Note>
  Midtrans can send its own reminder for a pending checkout. Follow the reminder only while the order and payment instruction are still valid.
</Note>

## PayPal checkout

For USD, complete approval in PayPal and return to AI Blueprint. The plan or add-on is granted only after AI Blueprint verifies the PayPal result. If you close or cancel PayPal, return to Billing and start or continue checkout as offered; a browser return by itself is not payment confirmation.

## Payment succeeded but access did not update

Do not repeat the payment immediately. Select **Check again** or refresh Billing once after the provider reaches a final successful state. Keep the order reference, provider, amount, payment method, and approximate time. Contact Support if the plan, credits, or invoice still does not appear.

## Failed, cancelled, or expired payment

No plan or credit grant is expected for a final failed, cancelled, or expired transaction. Start a new checkout from Billing. If this was the first plan attempt, the plan selector can appear again because no purchase has completed.

## A campaign coupon says checkout pending

The coupon is reserved by an earlier Midtrans checkout that has not reached a final state. Continue the valid checkout or cancel it before starting again. A final failed, cancelled, or expired order releases the coupon without granting its benefit. If the provider is already final but the reservation remains, keep the order reference and contact Support.

<Warning>
  Payment access is granted only after server-side provider verification. Never send a full card number, PIN, CVV, password, OTP, API key, PayPal credential, or browser cookie to Support.
</Warning>
